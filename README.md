# 네이버 ETF 라이브 대시보드

네이버 금융 ETF API 데이터를 실시간으로 조회해 운용사별, 투자시장별, 상품별로 비교하는 대시보드입니다.

## 배포 주소

- https://naver-etf-live-dashboard.fruitfulfoal2.chatgpt.site

## 주요 기능

- 30초 자동 갱신 및 수동 새로고침
- 운용사별 순자산 규모 분석
- 국내 지수·테마·파생·해외 주식·원자재·채권별 구성 분석
- 상품명·종목코드 검색과 운용사·시장 필터
- 시가총액, 수익률, 거래대금, 거래량 정렬
- 현재가, NAV 괴리율, 3개월 수익률 상세 조회

## 로컬 실행

```bash
npm install
npm run dev
```

네이버 API는 브라우저 CORS를 허용하지 않으므로 `app/api/etfs/route.ts`가 서버 측 프록시 역할을 합니다.

> 투자 판단을 위한 참고용 정보이며, 데이터 지연 또는 오류가 발생할 수 있습니다.
